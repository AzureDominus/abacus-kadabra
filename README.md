# Soroban Simple

A mobile-first PWA remake of a focused soroban practice app, implemented from scratch in React.

## Features

- Full-screen 7-column and 9-column soroban
- Soroban bead sounds, vibration, and swipe-to-reset gesture
- Active bead highlighting and optional digit values
- Classic, night, and paper themes
- Anzan invisible-soroban mode
- Built-in tutorials for basics, addition, subtraction, multiplication, and division
- Relax mode with untimed arithmetic drills and local badges
- Local persistence for preferences and progress
- iOS-friendly PWA manifest and service worker
- Aggressive PWA update checks with no-cache HTML, manifest, and service-worker headers

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run lint
bun run build
```
