# Abacus Kadabra

A mobile-first landscape PWA game for learning and practicing soroban-style abacus math.

## Stack

- Bun
- React 19
- TypeScript
- Vite
- TanStack Router
- vite-plugin-pwa

## Local Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

The app persists progress and settings in local browser storage and includes installable PWA metadata for iOS.
